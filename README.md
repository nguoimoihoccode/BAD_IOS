# CourtSide iOS (Native)

SwiftUI CourtSide app. Feature parity with Flutter `BAD_Mobile/platform`.

## Structure
- `Runner/` — app sources (features, core, theme)
- API base (simulator): `http://localhost:8000/api/v1`

## Setup
1. Create/open an Xcode project and add the `Runner` sources
2. Set deployment target iOS 16+
3. Run on simulator/device

## Git history
Commits are split by feature. Push to your own remote when ready.
